# ☁️ Preparatório AZ-900 · Microsoft Azure Fundamentals

Site do preparatório para a certificação **AZ-900 (Microsoft Azure Fundamentals)** da Profa. Maristela,
na Faculdade de Tecnologia e Inovação Senac DF.

**No ar:** https://maristelaoliveira.github.io/Preparatorio-AZ900/

## O que tem no site

- Os três domínios da prova, com os pesos do guia de estudo oficial.
- Dez encontros práticos (sala de aula invertida), cada um com prática guiada, desafio com caso,
  mini-simulado e a tarefa da quinzena.
- Progresso nas três trilhas do Microsoft Learn (salvo só no navegador de cada aluno).
- Lista dos vídeos curtos (os links ficam no Teams da turma).
- Treinos: "Qual é o serviço?" e um mini-simulado com explicação em cada resposta.
- O caminho até a prova e os links oficiais e gratuitos da Microsoft.

## Tecnologia

HTML, CSS e JavaScript puros, sem framework e sem etapa de build, no visual comum dos sites da Stela
(tema claro e escuro, aumento de texto e botão para pausar as animações).

Feito com ♥ e sucata eletrônica.
